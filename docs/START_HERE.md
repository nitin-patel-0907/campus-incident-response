## 🎬 DEMO INSTRUCTIONS

### 5-Minute Demo Flow

1. **Start the web app:**
   ```bash
   python app/app.py
   ```

2. **Open browser** to http://localhost:5000

3. **Click an example incident** (e.g., "Theft in Library")

4. **Click "Analyze Incident"**

5. **Watch the 5-agent workflow** process in real-time

6. **Review the complete analysis** showing:
   - Structured report from Prompt Agent
   - Action plan from Planner Agent
   - Safety validation from Safety Agent
   - Execution summary from Executor Agent
   - Evaluation scores from Evaluator Agent

7. **Show the dashboard** (optional)

## 📊 SAMPLE OUTPUT

For each incident, the system provides:

- **Overall Score:** 0-100 with effectiveness rating
- **Incident Classification:** Type, severity, location
- **Action Plan:** Immediate, short-term, long-term actions
- **Safety Validation:** Compliance status, violations, risk level
- **Execution Summary:** Tasks completed, resources allocated
- **Evaluation:** Strengths, weaknesses, recommendations
